# lab_01
Лабораторная работа №1
Компьютерная лексикография, терминологические базы (TBX) и Translation Memory (TMX) в Smartcat
ФИО студента: Зайцева Алёна Александровна Группа: ИНФА-221 Вариант: 4 (предметная область: Фармацевтика и клинические исследования)

Цель: научиться программно обрабатывать стандарты обмена терминологическими данными (TBX) и памятью переводов (TMX), реализовать поиск нечётких совпадений (Fuzzy Match) и подстановку терминов глоссария, экспортировать результат в CAT-систему Smartcat.

Ход работы: 
1. Создание и работа с терминологической базой TBX
2. Создание и обработка памяти переводов TMX
3. Использование метрик Levenshtein Ratio, Token Sort Ratio
4. Работа с различными типами совпадений (ICE, Fuzzy и т.д.)
5. Автоматическая постановка терминов глоссария в исходный текст.

Ссылка на работу: https://colab.research.google.com/drive/16z-ynpFAlGu85JR7RTpFOjSeqdWfZ54P?usp=sharing

Результат:
Создана терминологическая база из 100 терминов и база переводов, состоящая из 100 единиц для перевода на тему "Фармацевтика и клинические исследования". Автотесты были успешными.

Вывод: я сделала программу, которая помогает переводчику работать с медицинскими текстами. Она читает два файла: словарь терминов (TBX), где написано слово на английском и его перевод на русский (термины на тему Фармацевтика и клинические исследования), и память переводов (TMX), базу уже готовых переведённых предложений. Программа умеет искать в этой базе похожие предложения и показывать процент совпадения. В конце она сохраняет словарь в CSV-файл.
